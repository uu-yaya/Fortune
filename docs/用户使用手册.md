# 吉伊大师用户使用手册

- 更新日期：2026-03-08
- 适用对象：终端用户 / 内测用户

## 1. 怎么开始用

1. 打开系统地址
2. 登录账号
3. 进入聊天页直接提问
4. 公共设备使用后记得退出登录

## 2. 怎么问更容易得到有用回答

建议按这个顺序给信息：

1. 先说你想解决什么
2. 再说时间范围
3. 如涉及命理问题，再补资料

命理类资料建议：

- 姓名
- 出生日期（`YYYY-MM-DD`）
- 出生时间（越准确越好，不知道也可以先问）
- 性别（命理、正缘、部分媒体场景会用到）

例子：

- `我接下来30天的重点是什么？`
- `今年下半年事业上我该先做哪件事？`
- `我叫XX，2001-08-15，早上7点半出生，女生，想看今年财运节奏。`

## 3. 目前支持什么

1. 普通聊天与问候
2. 时间相关问答
3. 命理、运势、正缘、主题、方向、节奏类问题
4. 星座、解梦、占卜类问题
5. 连续追问
6. 直接问系统记住的资料，例如：
   - `我叫什么？`
   - `我的生日是？`
   - `我的出生时间是？`

## 4. 使用上的注意点

1. 命理类问题，资料越完整，判断越稳
2. 若没给出生时段，细节准确度会下降
3. 如果回答不够准，优先补背景和时间范围，而不是把同一句重复发多次
4. 若你问的是“我叫什么 / 我的生日 / 我的出生时间”，系统会优先直接回答事实信息

## 5. 当前限制

1. 回复属于参考建议，不替代医疗、法律、投资等专业意见
2. 外部能力偶发波动时，系统会给保守回答或提示稍后再试
3. 某些生成类或专项能力，可能受配置和环境限制，不保证所有部署环境都开启

## 6. 隐私与安全

1. 不要发送身份证号、银行卡号、验证码等敏感信息
2. 公共电脑上务必退出登录
3. 如发现明显错误回复、时间不一致、资料记错等情况，截图反馈给管理员

## 7. 遇到问题怎么办

1. 登录失败：先确认账号密码，再联系管理员
2. 回答不够聚焦：补背景、补时间范围、补资料
3. 生日/时辰回答不对：检查你之前是否已正确提供资料
4. 需要改密或新开号：走管理员流程
