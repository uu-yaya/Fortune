# 吉伊大师用户使用手册

- 更新日期：2026-03-08
- 适用对象：终端用户 / 内测用户

## 1. 怎么开始用

1. 打开系统地址
2. 登录账号
3. 进入聊天页直接提问
4. 公共设备使用后记得退出登录

## 2. 怎么问更容易得到有用回答

建议按这个顺序给信息：

1. 先说你想解决什么
2. 再说时间范围
3. 如涉及命理问题，再补资料

命理类资料建议：

- 姓名
- 出生日期（`YYYY-MM-DD`）
- 出生时间（越准确越好，不知道也可以先问）
- 性别（命理、正缘、部分媒体场景会用到）

例子：

- `我接下来30天的重点是什么？`
- `今年下半年事业上我该先做哪件事？`
- `我叫XX，2001-08-15，早上7点半出生，女生，想看今年财运节奏。`

## 3. 目前支持什么

1. 普通聊天与问候
2. 时间相关问答
3. 命理、运势、正缘、主题、方向、节奏类问题
4. 星座、解梦、占卜类问题
5. 连续追问
6. 直接问系统记住的资料，例如：
   - `我叫什么？`
   - `我的生日是？`
   - `我的出生时间是？`

## 4. 用户提问参考清单

下面这些问法，都是当前项目比较适合回答的方向。你不需要一字不差照抄，但越接近这些表达，命中越稳。

### 4.0 表格速查版

| 类型 | 可以问什么 | 示例问法 | 是否建议补资料 |
| --- | --- | --- | --- |
| 普通聊天 | 日常聊天、情绪支持、轻建议 | `今天有点烦，陪我聊两句` `给我一个今天能执行的小目标` | 否 |
| 时间 / 常识 | 日期、星期、基础时间问答 | `今年是多少年` `明天是几号` | 否 |
| 综合运势 | 年运、阶段趋势、整体走向 | `分析一下我今年的运势` `未来三年运势` | 是 |
| 短期运势 | 今日、明日、最近几天 | `今天运势如何` `明天整体运势` | 是 |
| 事业运 | 工作、职场、阶段重点 | `我最近事业运怎么样` `下半年事业上我该先做哪件事` | 是 |
| 感情运 | 感情趋势、恋爱状态、桃花 | `我最近感情运怎么样` `我这一阶段桃花运怎么样` | 是 |
| 通用财运 | 最近财运、收入节奏、财运重点 | `我最近财运怎么样` `最近收入运势如何` | 是 |
| 年度财运 | 某一年的财运 | `2027年财运如何` `明年财运如何` | 是 |
| 财运对比 | 两年或三年财运比较 | `今年和明年财运对比` `2026到2028年财运对比` | 是 |
| 财运决策 | 开源 / 守财 / 控支出 / 做副业 | `我这个月财运上该先开源还是先守财` | 是 |
| 姻缘趋势 | 婚缘、桃花、感情走向 | `我的姻缘趋势` `我最近婚缘走向怎么样` | 是 |
| 正缘画像 | 另一半类型、配偶特征 | `我的正缘画像是什么样` `适合我的伴侣是什么样的人` | 是 |
| 结婚预测 | 婚期、哪年容易结婚、婚缘节奏 | `我什么时候适合结婚` `我哪年容易结婚` | 是 |
| 星座运势 | 星座的今日 / 本周 / 本月 | `白羊座本周运势` `帮我看一下星座运势` | 否；有生日更方便自动推断 |
| 生肖运势 | 生肖的今日 / 本周 / 本月 | `属龙今日运势` `帮我看生肖运势` | 否；有生日更方便自动推断 |
| 择时 | 哪天适合做具体事项 | `下周哪天适合领证` `最近哪天适合搬家` | 一般不需要 |
| 解梦 | 梦境含义 | `梦见蛇是什么意思` `梦到考试迟到怎么解` | 否 |
| 占卜 / 摇卦 | 抽签、摇卦、短事判断 | `请帮我摇一卦` `我想占卜一下今天适不适合谈合作` | 否 |
| 记忆资料 | 问系统记住了什么 | `我叫什么你记得吗` `我的生日是` | 否 |
| 连续追问 | 在上一个问题基础上继续问 | `那事业这块展开说` `如果只看下半年呢` | 视话题而定 |

资料建议：

| 问题类型 | 建议提供 |
| --- | --- |
| 综合运势 / 财运 / 事业运 / 感情运 / 姻缘 / 正缘 / 结婚 | 姓名 + 出生日期 + 性别 |
| 想看更细的八字、流年、阶段判断 | 姓名 + 出生日期 + 性别 + 出生时间 |
| 星座 / 生肖 | 不强制；有出生日期更方便自动推断 |
| 解梦 / 占卜 / 普通聊天 / 时间问答 | 一般不需要资料 |

### 4.1 日常问候 / 普通聊天

- `你好呀`
- `你现在在线吗`
- `今天有点烦，陪我聊两句`
- `我最近有点焦虑，怎么调节一下`
- `给我一个今天能执行的小目标`
- `我最近睡不好，怎么调整作息`

适合这样问：

- 想要建议时，直接说困扰和目标
- 不需要补命理资料

### 4.2 时间 / 日期 / 常识类问答

- `今年是多少年`
- `今天星期几`
- `明天是几号`
- `下周是从哪天到哪天`
- `今天适合先处理工作还是先休息`

适合这样问：

- 如果只是问事实，不需要补资料
- 如果你想把“时间”结合命理来看，建议把问题说完整，例如 `下周哪几天更适合推进重要安排`

### 4.3 综合命理 / 运势趋势

- `分析一下我今年的运势`
- `明年运势`
- `未来三年运势`
- `我最近整体运势怎么样`
- `我接下来30天的重点是什么`
- `我下半年最该注意什么`
- `我最近事业运怎么样`
- `我最近感情运怎么样`
- `我现在的主题是什么`
- `我这一阶段应该稳一点还是冲一点`

适合这样问：

- 最好带时间范围：`最近`、`这周`、`这个月`、`今年`、`明年`
- 这类问题建议提供：姓名、出生日期、性别
- 如果知道出生时间，也可以一起说，结果会更细

### 4.4 今日 / 明日 / 近期运势

- `今天运势如何`
- `我今天财运如何`
- `我今天事业运怎么样`
- `我今天感情运如何`
- `明天整体运势`
- `这几天我的状态会不会顺一点`

适合这样问：

- 想看短期节奏时，用 `今天 / 今日 / 明天 / 最近几天`
- 如果你问得越具体，回答越聚焦，例如 `我今天适合推进沟通吗`

### 4.5 财运问题

当前财运问题分成三类：

1. 通用财运

- `我最近财运怎么样`
- `我这阵子财运顺不顺`
- `最近收入运势如何`
- `我现在财运的重点是什么`

2. 年度财运

- `2027年财运如何`
- `今年财运怎么样`
- `明年财运如何`
- `2028年收入走势怎么样`

3. 财运决策 / 财运对比

- `今年和明年财运对比`
- `2026到2028年财运对比`
- `我这个月财运上该先开源还是先守财`
- `这阵子财运我该先扩收入还是先控支出`
- `最近我该先稳现金流还是先做副业`

适合这样问：

- 想看某一年，请直接说年份
- 想做对比，建议最多说 2 到 3 年
- 想要明确建议，就用 `先A还是先B`

### 4.6 姻缘 / 感情 / 正缘 / 结婚

1. 姻缘趋势

- `我的姻缘趋势`
- `我最近婚缘走向怎么样`
- `我的感情趋势接下来会怎么发展`
- `我这一阶段桃花运怎么样`

2. 正缘画像

- `我的正缘画像是什么样`
- `我的另一半大概是什么类型`
- `适合我的伴侣是什么样的人`
- `我未来配偶的特征是什么`

3. 结婚 / 婚期 / 婚缘节奏

- `我什么时候适合结婚`
- `我的婚期怎么看`
- `我哪年容易结婚`
- `结婚预测`
- `我适不适合这两年结婚`

适合这样问：

- 这类问题建议资料尽量完整：姓名、出生日期、性别，最好再补出生时间
- 正缘问题会更偏人物画像和相处方式
- 结婚问题会更偏婚缘节奏、容易进入婚姻的阶段

### 4.7 星座运势

- `帮我看一下星座运势`
- `白羊座本周运势`
- `双鱼座今日运势`
- `狮子座这个月工作运怎么样`
- `天蝎座明天感情运`
- `巨蟹座最近财运如何`

适合这样问：

- 直接说具体星座会更快
- 如果你没说星座，但资料里有生日，系统会优先自动推断
- 星座问题不需要出生时间

### 4.8 生肖运势

- `帮我看生肖运势`
- `属龙今日运势`
- `属马本周运势`
- `属狗这个月工作运`
- `属兔最近财运怎么样`

适合这样问：

- 直接说 `属龙 / 属狗 / 属马` 这类表达最稳
- 如果你没说生肖，但资料里有生日，系统会优先自动推断
- 生肖问题不需要出生时间

### 4.9 择时 / 哪天更适合做某件事

当前更适合问“具体事项 + 具体时间段”的问题：

- `下周哪天适合领证`
- `下周哪天适合搬家`
- `最近哪天适合出行`
- `这周哪天适合订婚`
- `下周哪天适合开业`
- `最近哪天适合去看病`

适合这样问：

- 直接说事情：`领证 / 搬家 / 出行 / 订婚 / 开业 / 求医`
- 再说时间段：`今天 / 下周 / 最近几天`
- 如果你只问得很抽象，例如 `最近怎么安排更顺`，系统更可能给趋势建议，而不是具体某一天

### 4.10 解梦

- `梦见蛇是什么意思`
- `梦到掉牙怎么解`
- `梦见前任是什么意思`
- `梦到考试迟到是什么意思`
- `我昨天梦见下雨和迷路`

适合这样问：

- 直接说梦里的核心画面最有用
- 不需要补命理资料
- 不需要把梦写成很长一段，关键词清楚就行

### 4.11 占卜 / 摇卦 / 抽签

- `请帮我摇一卦`
- `我想占卜一下今天适不适合谈合作`
- `帮我抽一签`
- `我今天适不适合推进这个决定`
- `我最近这件事的卦象怎么样`

适合这样问：

- 如果有具体事项，建议一起说，例如 `谈合作 / 签约 / 复合 / 换工作`
- 不需要补出生资料

### 4.12 记忆 / 已记录资料查询

- `我叫什么你记得吗`
- `我的生日是`
- `我的出生时间是什么`
- `你记得我的性别吗`

适合这样问：

- 这类问题会优先直接回答已记住的信息
- 如果资料没记住或没提供过，系统会提示你补充

### 4.13 连续追问

你可以在同一个话题下继续往下追，不需要每次都重新解释背景。

例如：

- `先看我今年运势`
- `那事业这块展开说`
- `再具体讲讲财运`
- `如果只看下半年呢`
- `那我该先稳还是先冲`

再例如：

- `帮我看正缘画像`
- `那相处模式呢`
- `更容易在哪里认识`
- `这两年机会大吗`

### 4.14 推荐问法模板

如果你不确定怎么组织，可以直接套下面这些模板：

- `我想看【主题】，时间范围是【时间】，我最关心【重点】。`
- `我叫【姓名】，生日【YYYY-MM-DD】，性别【男/女】，想看【问题】。`
- `帮我判断【A】还是【B】更适合我，时间范围是【时间】。`
- `下周 / 最近几天，哪天更适合【具体事项】？`
- `我梦见【关键词】，这代表什么？`
- `帮我占卜一下【具体问题】。`

## 5. 哪些情况建议先补资料

下面这些问题，补齐资料后会明显更准：

1. 综合运势、流年、财运、事业运、感情运
2. 姻缘趋势、正缘画像、结婚预测
3. 方向、主题、节奏、阶段判断
4. 决策类命理问题，例如 `先开源还是先守财`

建议资料顺序：

1. 姓名
2. 出生日期
3. 性别
4. 出生时间

## 6. 哪些问法目前不够理想

1. 太短、没有主题
   - 例如：`看看`、`帮我算`
2. 没有时间范围，但又希望得到阶段判断
   - 例如：`我运势怎么样`
3. 想看具体择日，但没说具体事项
   - 例如：`最近哪天更顺`
4. 想做多年对比，但范围太大
   - 例如：`未来十年财运对比`

更好的改写方式：

- `我最近一个月运势怎么样`
- `下周哪天适合搬家`
- `今年和明年财运对比`
- `我现在该先开源还是先守财`

## 7. 使用上的注意点

1. 命理类问题，资料越完整，判断越稳
2. 若没给出生时段，细节准确度会下降
3. 如果回答不够准，优先补背景和时间范围，而不是把同一句重复发多次
4. 若你问的是“我叫什么 / 我的生日 / 我的出生时间”，系统会优先直接回答事实信息

## 8. 当前限制

1. 回复属于参考建议，不替代医疗、法律、投资等专业意见
2. 外部能力偶发波动时，系统会给保守回答或提示稍后再试
3. 某些生成类或专项能力，可能受配置和环境限制，不保证所有部署环境都开启

## 9. 隐私与安全

1. 不要发送身份证号、银行卡号、验证码等敏感信息
2. 公共电脑上务必退出登录
3. 如发现明显错误回复、时间不一致、资料记错等情况，截图反馈给管理员

## 10. 遇到问题怎么办

1. 登录失败：先确认账号密码，再联系管理员
2. 回答不够聚焦：补背景、补时间范围、补资料
3. 生日/时辰回答不对：检查你之前是否已正确提供资料
4. 需要改密或新开号：走管理员流程
