## 5. 文档维护规则

1. 改系统能力、路由策略、provider 映射时，必须同步更新 `01 / 02 / 34`。
2. 改公开接口、返回结构、资料门禁时，必须同步更新 `04`。
3. 改回归脚本、发布前验收集、关键测试范围时，必须同步更新 `05`。
4. 改存储结构、Redis key、资料字段时，必须同步更新 `03 / 06`。
5. 改用户可见交互时，必须同步更新 `用户使用手册.md`。
6. 新增一次性回归快照时，不默认写进 `docs/` 主目录；优先放 `docs/generated/`，并在任务完成后清理。
